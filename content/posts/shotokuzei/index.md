所得税を決めるにはまず、所得を計算する。

所得は、売上から経費を引く。

```
所得 = 売上 - 経費
```

売上は、商品やスキルを売ってダイレクトに入ってくるお金。

経費は、売上をあげるために必要なお金。

次に、所得から控除を引く。

```
課税所得 = 所得 - 控除
```

控除は、子供がいたら扶養控除、保険を支払っていたら社会保険控除などがあり、所得から差し引く。

この差し引いたものが**「課税所得」**というもになる。

課税所得に所得税率をかけることで、自分が支払う所得税額が分かる。

```
所得税額 = 課税所得 × 所得税率
```

所得税率は、[国税庁のホームページ](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm)で確認できる。
